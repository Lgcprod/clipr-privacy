Why does the Clipr keyboard need Full Access?

Because without it, iOS gives a third-party keyboard no way to reach the storage where your clips already live. Full Access is the only switch that lets the keyboard read Clipr's own container.

It is not used for anything else. The keyboard does not record what you type, does not log keystrokes, and has no networking code to send anything anywhere. iOS never exposes secure fields such as passwords to third-party keyboards at all. The privacy policy covers this in full.

The keyboard is optional. Clipr works without it — you just copy from the app instead of inserting from the keyboard.

The keyboard says “No saved clips yet” but I have clips

Two causes, in order of likelihood:

  • Full Access is off. Settings → General → Keyboard → Keyboards → Clipr → Allow Full Access.
  • An older build is still installed. If you ever ran a TestFlight or development copy of Clipr, it may have left a second keyboard with the same name pointing at its own empty storage. Delete the old app and re-add the keyboard.

How do I add the keyboard?

Settings → General → Keyboard → Keyboards → Add New Keyboard → Clipr. Then tap Clipr in the list and turn on Allow Full Access. Clipr's Keyboard tab has a Set Up Keyboard button that opens the right screen for you.

What does Clipr Pro include?

Unlimited saved clips. The free version keeps five. Everything else — the keyboard, the Messages panel, folders, favourites, search, undo, export — works the same either way.

Pro is a one-time purchase, not a subscription. There is no account to create and nothing recurring to cancel.

I paid for Pro but it is not showing

Open Clipr → Settings → Upgrade to Pro, then tap Restore Purchases. That asks the App Store directly, and it is the right fix after restoring a backup, switching phones, or signing in with a different Apple Account.

Purchases are tied to the Apple Account that bought them. If you bought Pro on one account and are signed in with another, the restore will correctly find nothing — sign in with the original account and try again.

Where are my clips stored? Can I get them back?

On your iPhone, and nowhere else. Clipr has no server and no account, so there is no copy of your clips for us to recover.

That also means deleting the app deletes your clips. Before you delete Clipr, or before switching phones, use Settings → Export All Clips to save a JSON backup somewhere you keep — Files, iCloud Drive, anywhere you choose. Settings → Import Backup reads it back in later.

Does Clipr watch my clipboard in the background?

No. It reads your clipboard at exactly one moment: when you tap the button asking it to save what you copied. iOS may show its own paste confirmation when that happens, which is the system telling you the truth about what is going on.

Face ID is not available

Clipr's optional lock uses whatever your iPhone already has set up. If Settings says biometric lock is unavailable, Face ID or Touch ID has not been enrolled on the device, or Clipr has been denied Face ID in iOS Settings → Clipr.
